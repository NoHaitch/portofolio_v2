# Assistant knowledge

This folder contains manually curated facts that the portfolio assistant may use when answering public questions about Francisco.

Only add information that is approved for visitors to see.
Do not copy private notes or credentials into this folder.

## Files and sources

- `profile.md` contains stable profile facts that do not belong to one specific project.
- `education.md` contains approved ITB program, training, and transcript details.
  Its `###` headings define individually retrievable sections.
- Portfolio project summaries and a page guide are assembled from the published site content when the retrieval corpus is built.
  Update the source work entries and routes rather than maintaining a duplicate project list.
- Project and activity details should come from `content/work/projects/` and `content/work/activities/`.
- Add facts from GitHub or LinkedIn here only after verifying them and recording the public source URL.
- Prefer the portfolio's published content when it already covers the same fact.

## Adding information

Write short, factual sections with one topic per heading.
Include a source link for claims that can change, such as a role, project status, or external profile detail.
Use dates where they clarify when a fact applied.
Separate confirmed facts from goals, interests, or personal opinions.
Do not inflate achievements or infer details that are not stated in a source.

This content is part of the retrieval corpus used by the public assistant and admin AI playground.
Edit it to change what the assistant knows, then ask a known question and an unsupported one to check grounding.
Only add public information, because retrieved passages are sent to the model provider and may appear in answers.
