## Overview

Pilkehi was built for the 2021 election of the student association chair at Himpunan Mahasiswa Ilmu Komunikasi
Universitas Padjadjaran (Hima Ilkom Unpad). The website provided login and voting flows, along with administrative
pages for viewing user data and election results.

## My contribution

I worked on the project with Belati Jagad Bintang Syuhada, a friend from Five Cyber Community (FCC). I was responsible
for the backend, including the login and voting system, connecting the frontend forms to the backend, and setting up
the server hosting and database.

I also contributed to the UI/UX and frontend. We brainstormed the initial structure, developed and revised the design
in Figma, and added pages for specific errors and administration as the project took shape.

## Implementation and lessons

The interface used HTML, CSS, JavaScript, and Bootstrap. The backend used PHP and MySQL through `mysqli`, with XAMPP
as part of the development setup. This structure connected the website's login and voting forms to stored data and
made the election results available through administrative pages.

This was my first paid web project and an opportunity to take independently learned web development into a
collaborative delivery. I gained practical experience working across the backend, frontend integration, database, and
hosting, while adapting the design as additional needs became clear.
